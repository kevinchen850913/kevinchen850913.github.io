# 重點不要直接講明 有些文字，寫得太快，就會太直白。你一開始會很自然地把感受講清楚，比如我今天心情不好、我覺得很孤單，這些話說出來沒什麼錯，但那只是一種解釋，對方聽見了，卻不一定能感受到。 後來你會開始練習，把真正的情緒藏起來一點，不說破。你不說「我難過」，而是描述房間裡一直沒關的燈。你不說「我害怕」，而是寫有人敲了三次門，但你沒打開。 讀者會感覺到的，甚至比你感受得更多更深。這不是故弄玄虛，而是讓文字有餘地。你越不急著解釋，讀者就越能進來，自己感受。寫作的第一步，不是把情緒寫明白，而是學會不講穿。不要寫答案，寫氣味。 # 專注在單一的情感 文章可以寫日常，可以寫一碗泡麵、一場對話、一段沉默，但背後的情緒要專一。你必須選一種感覺，專心地鋪陳它，讓它慢慢地擴散。這樣讀者才會感覺到你在說一件事，而不是列出你今天經歷了多少件小事。 你可以寫輕鬆，可以寫懊悔，可以寫安心或慌張，但不要每種都碰一下。當情緒變得模糊不清，文章也會跟著變得空洞。不是平易近人，而是輕飄無重。寫文章其實和講話一樣，重點不是你說了多少，而是你讓對方感覺到了什麼，通常一篇文章專注在單一的情感就好。 # 每次檢查刪減 10% ...
