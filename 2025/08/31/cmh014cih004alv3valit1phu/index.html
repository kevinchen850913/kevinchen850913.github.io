LeetCode 解題筆記 priority_queue

發表於2025-09-01|更新於2025-10-21

題目 : 1792 最大平均通過率

有一所學校有好幾個班級，每個班級的學生都要參加期末考。你拿到了一個二維陣列 classes，其中的每一筆資料 classes = 通過人數，總人數，代表第 i 個班級有多少人會通過考試，以及班上總共有多少人。

除此之外，你還有一個額外的整數 extraStudents，表示有這麼多非常優秀的學生可以任意分配到班上，而且不管他們被分配到哪個班級，都一定會通過考試。

你的目標是，將這些優秀的學生分配到各個班級中，讓所有班級的平均通過率達到最大。

# 我的解題思路

看到題目就先開始猜題，這題可能是要考什麼呢？有沒有什麼特別的解法？或者能不能用數學的方式直接解？想一圈後還是覺得常見策略都不太適用，所以猜測這題的正解應該是屬於「貪婪算法」的範疇。

那要怎麼貪婪呢？我先把問題簡化，不去管有多少個優秀的學生，而是先想：如果現在只有一位優秀學生，那把他安排到哪個班級會最有價值？想清楚這一點之後，再一個一個把剩下的學生依序放進去，直到放完為止，就能得到解答。

那要怎麼算「價值」呢？其實很直觀。假設某個班級現在有 A 個通過、B 個學生，那通過率就是 A/B。如果我們加入一位一定會通過的優秀學生，通過率就會變成 (A + 1)/(B + 1)。兩個通過率相減，就是這位學生對這個班級帶來的增益。

實作上，我需要一個容器來存每個班級目前的通過人數、總人數，以及加入後的增益。直覺上我用了 vector<vector<double>> 來處理。接下來的問題是：怎麼避免每次都重算全部的班級？

這裡我用了類似 DP 的想法。因為每次只會有一個班級被改動，我只需要更新這個班級的資料，其他部分並不需要重算，這樣整體會更有效率。

# 答案的差異

主要的差別是 priority_queue 會比 vector<vector<double>> 更快的找出最大值，所以我選錯容器了，這就是我超時的原因。

使用 vector

  • 每次都用 for loop 找出 vec 中的最大值。
  • 這是 O (n) 的操作（每次都要掃一次整個列表）。

使用 priority_queue

  • 每次取最大增益值是 O (1)，更新後重新放入堆中是 O (log n)。
  • 總體效率 O (k・log n)，明顯比你的 O (n・k) 快得多。

# priority_queue

priority_queue 是一種基於堆的容器適配器，它不像 vector 那樣可以任意訪問元素，但它能以 O (1) 時間快速取得最大值，並以 O (log n) 時間插入或刪除最大值。

特性 vector priority_queue
隨機存取 ✅ ❌
直接取出最大值 ❌ ✅
直接刪除最大值 ❌ ✅
排序保持 ❌ ✅
支援遍歷 ✅ ❌

一些簡單的範例

priority_queue 為什麼是 "最大堆"，而不是 "有序佇列"?

實作基礎事實：priority_queue 通常是基於「堆（heap）」實作的，它的底層預設是用 vector 搭配 make_heap, push_heap, pop_heap 等操作組成的 最大堆（max heap）。所以從實務與效率角度看，它是「堆」而非「佇列」或「排序」容器。

名稱的誤導：priority_queue 聽起來像是「有順序的佇列」，但其實它不是像 queue 那樣 FIFO，也不是像 set 那樣保持排序。

所以翻譯為最大堆，能幫助理解它的真正用途與效率特性。

  • 只能隨時 快速取出最大（或最小）值。
  • 不能遍歷它的內部資料順序。
  • 每次 pop () 的是「目前最大值」。

priority_queue 的順序不是使用類似紅黑樹的方式來實作？

不是的，priority_queue（在 C++ STL 中）並不是用紅黑樹或平衡樹實作的，而是用「堆（heap）」實作的。

特性 priority_queue （heap） 紅黑樹（如 std::set , std::map ）
實作結構 binary heap 平衡二元搜尋樹
插入效率 O(log n) O(log n)
查找最大 / 最小 O(1) 遍歷最左 / 右節點
遍歷所有元素 沒有順序 支援有序遍歷
刪除任意元素 不支援 O(log n)
