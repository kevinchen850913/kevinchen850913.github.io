VirtualBox Gitlab 搬家筆記

發表於2025-08-08|更新於2025-08-08

今年開始 Gitlab 用的電腦會偶發當機，而最近剛好有電腦可以替換使用，所以開始嘗試搬運 VirtualBox Gitlab 資料與設定檔到另外一台電腦，隨手記錄搬運的過程，遇到的問題與解決對策。

# 舊電腦備份 GitLab 資料

你需要找到需要的備份檔案，然後將它們傳送出去。這些檔案通常會包括 GitLab 備份檔 和 設定檔，這樣你才能在新電腦上完整還原 GitLab 環境。

使用 gitlab-backup 建立備份檔案

複製設定檔，可以搬出權限範圍，再使用 GUI 操作

Ubuntu 中打開 Terminal : Ctrl + Alt + T

# GitLab 備份檔案

這些是 GitLab 的數據備份，通常包含你的所有 repository、CI/CD pipelines、issues 等。它們位於 /var/opt/gitlab/backups/ 目錄下。

  • 備份檔案的格式通常是 .tar ，例如：1234567890_2023_08_01_gitlab_backup.tar
  • 你可以用 ls /var/opt/gitlab/backups/ 查找當前的備份檔案。

# GitLab 設定檔

這些是 GitLab 的配置檔案，包括 GitLab 的系統設置、密鑰等。這些檔案位於 /etc/gitlab/ 目錄下。

  • gitlab.rb：GitLab 的主要配置檔案
  • gitlab-secrets.json：包含一些重要的機密配置，必須一起備份。

# GitLab 匯出失敗對策

虛擬機上執行 gitlab-backup 指令時遇到「找不到指令」的問題，可能是因為 GitLab 的備份工具 gitlab-backup 沒有安裝或未正確配置。

可以進入 /var/opt/gitlab/backups/ 這個目錄檢查，你需要有 root 權限，因為這個目錄是由 GitLab 建立的，權限比較嚴格。

可以用 sudo -i 切換為 root 使用者

可以嘗試直接使用 gitlab-rake 命令

# 搬移備份檔案到新電腦

我是使用 VirtualBox 共用資料夾，將檔案抓出虛擬機環境，複製一份到 USB，再將檔案轉移到新環境，這樣備份檔案可以簡單的使用 Windows 管理。若是多台電腦都會繼續使用，建議設定 SCP 方案，未來可以更方便傳檔案。

# SCP 指令方案

Secure Copy Protocol 可以讓你在本機與虛擬機之間（或任兩台電腦之間）透過 SSH 安全地傳輸檔案。這是跨平台（Linux、Windows、macOS）通用的方法，不需要啟用 VirtualBox 的拖曳或共用資料夾功能。

  • 虛擬機有安裝 openssh-server 並正在運行
    • sudo systemctl status ssh
  • 主機能連線虛擬機（透過 IP 或 Port Forwarding）：
    • 若使用 NAT 模式 → 建議設 Port Forwarding（例如把虛擬機的 SSH 22 對應到主機 2222）
    • 若使用 Host-Only 或 Bridge → 直接使用虛擬機的 IP，例如 192.168.56.101
      知道虛擬機帳號，例如 ubuntu、gitlab 或其他登入用戶名。

從虛擬機傳送到主機

主機執行 scp 從虛擬機抓檔案

-P 指定連接埠，your_vm_user 是虛擬機內部使用者帳號。

# VirtualBox 共用資料夾

共用資料夾是更穩定、跨平台的替代方案。以下是在 VirtualBox 中設定共用資料夾的完整方法，適用於 Windows 主機 + Linux/Windows 虛擬機的常見情境。

VirtualBox 設定方法

項目 說明
資料夾路徑 主機上的資料夾路徑，例如： D:\\VMShared 或 /home/you/shared
資料夾名稱 建議簡單命名，例如：shared（這會是虛擬機看到的名稱）
自動掛載 ✅ 打勾
固定分配 ✅ 打勾（建議）

在虛擬機裡掛載共用資料夾（例如： shared）

重啟虛擬機

複製 GitLab 備份到共用資料夾

# VirtualBox 拖移檔案

在 VirtualBox 中拖曳（Drag and Drop）檔案的功能允許你在主機（Host）與虛擬機（Guest）之間拖拉檔案。這功能不是預設啟用，且有些限制。

  1. 安裝「Guest Additions」 到虛擬機中。
  2. 虛擬機使用的是 GUI 介面（非純 CLI 模式）。
  3. 虛擬機 OS 支援拖曳功能（例如 Windows、Ubuntu Desktop）。

安裝 Guest Additions

然後掛載 Guest Additions，安裝完後，重啟虛擬機。

可能失敗的情況與解法

問題 原因 解法
拖曳無效 Guest Additions 未正確安裝 重新安裝 Guest Additions
拖曳選項灰色 虛擬機未關機 完全關機後再啟用
拖曳後沒反應 使用者權限不足 用管理員權限啟動虛擬機或檔案總管
Linux 無法拖入檔案 檔案總管或桌面環境不支援 使用共用資料夾（更穩定）
