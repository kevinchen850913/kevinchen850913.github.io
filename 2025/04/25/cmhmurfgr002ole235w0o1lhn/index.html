FTDI SetBitMode 的使用方法

發表於2025-04-26|更新於2025-11-06

# 函數原型

使用 FT_SetBitMode 可以讓你以程式方式控制 FTDI 裝置的 I/O 腳位方向（輸入或輸出）及其工作模式，非常適合嵌入式開發、通訊模擬或硬體控制等應用。

Set the device IO bit mode.
設定 FTDI 裝置的 I/O 位元（bit）工作模式。

Parameters
ftHandle
Handle of the device.
裝置的控制代碼（handle），代表你想要操作的那個 FTDI 裝置。

ucMask（位元遮罩）
Required value for bit mode mask. This sets up which bits are input and which bits are output. The ucMask byte sets the direction. A ‘0’ means that the corresponding bit is to be an input, while a ‘1’ means that the corresponding bit is to be an output.
用來設定哪一個位元是輸出、哪一個是輸入。

  • 如果一個位元是 0 ，代表那個 I/O 腳位是「輸入」模式。
  • 如果一個位元是 1 ，代表那個 I/O 腳位是「輸出」模式。
    這個遮罩是針對所有 8 個位元的設定。

ucMode
Mode value as shown in the following table:
設定裝置的工作模式，以下是支援的模式：

Mode 說明 Value (hex)
Reset the IO Bit Mode 重置 I/O 模式，回到預設狀態。 0x0
Asynchronous Bit Bang Mode 透過簡單方式控制 I/O 腳位輸出，非同步。 0x1
MPSSE 用於 SPI/I2C/JTAG 等高級協議通訊。 0x2
Synchronous Bit Bang Mode 類似 Bit Bang，但為同步模式。 0x4
MCU Host Bus Emulation 模擬 MCU 匯流排介面。 0x8
Fast Serial For Opto-Isolation 用於高速、帶有光隔離的序列通訊。 0x10

Return Value
FT_OK if successful, otherwise the return value is an FT error code.
如果設定成功，回傳 FT_OK。如果失敗，則回傳一個錯誤代碼（FT error code）。

# 參數說明

ucMask 與 ucMode 是分別發揮作用的：

  • ucMode 是設定整體工作模式的，也就是這個裝置目前在使用哪一種通訊或控制模式（如 Bit Bang、MPSSE、Reset…）。
  • ucMask 是在某些模式下的輸出 / 輸入設定，尤其是「Bit Bang 模式」相關模式下才會生效。

FTDI 多功能腳位（multiplexed）
FTDI 晶片的 I/O 腳位不是專用的 GPIO，而是經過「模式切換」來扮演不同功能：

模式 功能
UART 模式（預設） 腳位負責傳輸 UART 資料
Bit Bang 模式 腳位作為數位 I/O 腳位，輸出高或低電位
MPSSE 模式 腳位變成 SPI、I2C、JTAG 等協議訊號線

# 標準通訊狀態

如果你的 ucMode 設為 0（十六進位為 0x00），代表的是 Reset 模式（重設 I/O 位元模式），設定 ucMode = 0 表示你要 重設裝置的 I/O 狀態回預設模式，也就是 關閉 Bit Bang 或其他特殊 I/O 模式，讓裝置回到最基本、標準的 USB 通訊狀態。

  • 會關閉 Bit Bang 模式（如果之前開啟過的話）。
  • I/O 腳位會被還原為預設狀態（通常是輸入）。
  • ucMask 的值在這種模式下會被忽略，因為根本不會使用遮罩。
  • 這個動作只是重設 I/O 模式，不會重啟或重設整個裝置。
  • 如果你之後想再控制 I/O，就需要重新設定 ucMode 和 ucMask。

# I/O 控制狀態

如果你只是想控制 FTDI 裝置的 I/O 腳位電平高（High）或低（Low），可以使用 Bit Bang 模式。這是最直接的方式讓你用程式控制哪一個腳位輸出 1 或 0（也就是高電位或低電位）。
