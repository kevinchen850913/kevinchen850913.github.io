2025 年初電腦整理記錄

發表於2025-01-20|更新於2025-11-06

今年我的電腦已經使用超過五年了，所以想來對電腦動一些手腳。那為什麼不直接換一台電腦？小朋友才做選擇，我就是又要升級又要買新電腦，預計今年會組新電腦，而舊電腦則會挪作其他用途。

另外我還有一台筆電今年準備退役，征戰 10 年，經過多次改造，目前已經準備報廢。到現在就連 Ubuntu 也開始不敷使用，遂不打算繼續維護。

WIN7 => WIN10 => WIN10 精簡版 => Ubuntu

2025 電腦裡理計畫

  • 十年筆電 => 廢棄不維護
  • 五年桌機 => 整理部分零件
  • 新買電腦 => 未來想玩 AI

想改善的問題

  • 記憶體長期滿載，系統碟 SSD 也被塞滿，記憶體塞滿，電腦會把資料搬到硬碟，而 SSD 的特性是剩餘過少時效能會變差，雙管齊下，害我每次開軟體都有夠卡。
  • 風扇有些異音，感覺就是貓貓的問題，因為我有養貓，目前已執行一些對策，把主機改放置在桌上，減少主機吸入貓毛，那解決方法就是拆開清潔，認真面對那些貓毛。

# 添購 1T SSD

目前電腦上有 SSD 250GB + HDD 1T，
下單 SSD 1T (M2) 取代 SSD 250GB，
要注意的是我的主機板 M2 與 PCIe 會共用資源。

# 添購 32G RAM

目前電腦上有兩條 DDR4 8G，下單兩條 DDR4 16G，
記憶體兩條改成四條，所以插槽排列方式也需要稍微調整。

  • CPU (參考位置)、A1、A2、B1、B2
  • 一條狀況 : A1、A2、B1、B2 (8G)
  • 兩條狀況 : A1、A2 (8G)、B1、B2 (8G)
  • 四條狀況 : A1 (8G)、A2 (16G)、B1 (8G)、B2 (16G)

# USB WIN10、WIN11

提前準備重灌專用 USB，一隻只要 100 元很便宜，
網購的時候順便買了三隻，額外幫朋友製作一支，
後來覺得還是買太少了，下次網購可以多買 Type-C 版本。

# 原價屋購物

  1. 前往估價系統選擇零件
  2. 網頁使用信件寄送需求單
  3. 電話客服確認基本資訊
  4. 信件收取報價單
  5. 銀行轉帳付款
  6. 等待黑貓宅配到家

補充：查價格約比蝦皮便宜 200 元。

# 電腦要怎麼安裝

移除電腦中各式零件，記憶體只安裝一條，
螢幕使用內顯開機，檢查是否成功進入 WIN。

如果未顯示 BIOS 開機訊息，
可能是記憶體安裝時接觸不良導致，
可以在測試過程中重新插拔與清潔，
若是其他元件異常，則 BIOS 通常要能正常顯示。

關機後重新插上另外一條記憶體，
螢幕使用內顯開機，檢查是否成功進入 WIN。

總之就是一個零件一個零件裝上去，
後要注意不要火線作業，確認主機版熄燈再作業，
如果無法開機，就可以知道是哪個零件安裝不當，
或極小概率遇到零件真的有問題。

# 新電腦更新

如果處理程序依舊耗用過多 CPU，那麼問題可能出在驅動程式版本過時或差強人意。驅動程式是控制連接到主機板的特定裝置之程式。更新驅動程式可能會解決造成 CPU 使用率增加的相容性問題或錯誤。

開啟「開始」功能表，接著開啟「設定」。按一下「更新與安全性」，然後按一下「檢查更新」按鈕。這將會更新關鍵驅動程式。顯示卡製造商也提供公用程式（例如針對 GPU 的 Nvidia GeForce Experience），可在玩遊戲時提升整體效能。

CPU-Z 是一個可靠工具，能檢查與 CPU 和主機板相關的一般資訊。它會顯示 CPU 與主機板的確切型號以及效能資訊。您可以使用這些型號在線上搜尋 CPU 使用率方面的支援討論串。

# 推薦關閉設定

暫停 OneDrive 同步
如果您使用 Microsoft OneDrive 將檔案儲存至雲端，您的電腦將會與雲端之間持續執行同步動作。不論是從桌上型電腦或是網頁瀏覽器存取，此作法可使得檔案獲得適當的儲存。此同步動作會佔據電腦關鍵資源，進而降低電腦的速度。

垃圾微軟，我明明就記得安裝時我有選擇不要使用 OneDrive，結果還是自動幫我開啟 OneDrive 同步下載了一些垃圾檔案，然後再提示我 OneDrive 空間不足，我同步使用 NAS 就足夠了。

工作管理員開機選項
關閉所有開機自動執行的軟體，限制電腦開機時會自動啟動的程式數量，可顯著提高效能。有些程式開機時一定要啟動，但有些程式可能沒必要。停用不必要的程式，能縮短電腦開機所需時間，並提高整體回應速度。

停用特殊效果
Windows 10 中 效能選項 中的 視覺效果 索引標籤
Windows10 有一系列的特殊效果，可以讓使用者視覺感官體驗更好。這些效果都是由 Windows 所預設以及其他功能所編制的淡入與淡出視圖。而其他會增加降低速度的特殊功能，包含半透明和動畫效果。

開啟 Windows 功能表並搜尋 系統，然後前往 進階系統設定 索引標籤，並前往 進階 索引標籤，然後選取 效能設定。按一下 視覺效果 索引標籤，然後按 自訂 選項按鈕。視覺效果清單隨即顯示，您可以取消勾選方塊以停用這些效果。完成後，按一下 套用 以確認您的變更。

除了浪費系統資源來顯示動畫等功能以外，Windows 10 還將某些功能 (如工作功能表) 設計透明效果。這個看似輕巧簡單的效果，實際上相當複雜，其佔用的系統資源比您想像的要多。

若要停用透明效果，開啟 Windows 功能表然後在搜尋列輸入 顏色設定，以提取 Windows 10 的 顏色 設定。從此處向下捲動，直到找到 透明效果 按鈕為止。按一下此按鈕，以啟用或停用透明效果。
