Embedded Resources 讓程式免依賴外部檔案

發表於2025-05-03|更新於2025-12-22

內嵌資源（Embedded Resources）是一種將文件（例如文本檔案、圖片、配置檔案等）嵌入到編譯後的程式集中，使得這些文件在執行時可以通過程式碼存取的方式。這樣做可以將資源和應用程式一起打包，避免了依賴外部文件的需求，從而使得部署和發佈變得更加簡單，特別是在某些不便管理或分發外部文件的情境下。

內嵌資源的優點

  • 部署簡單：所有的資源文件都成為程式的一部分，不需要另外提供文件。
  • 安全性：內嵌資源在編譯過程中被打包，可以減少外部文件被篡改的風險。
  • 提升效能：將常用的文件嵌入程序集中，可以避免在執行時從外部來源（如磁碟或網絡）讀取，從而提高存取速度。

內嵌資源的注意事項

  • 資源名稱：內嵌資源名稱大小寫敏感，因此要確保資源名稱完全匹配，包括命名空間、資料夾和檔案名稱。
  • 效能考量：儘管將資源內嵌在程式集中有其優勢，但過多的內嵌資源可能會導致應用程式的大小增加，因此在使用時應適度選擇。

# 如何增加內嵌資源

  1. 將文件添加到專案中，在 Visual Studio 中，右鍵單擊專案中的某個資料夾或專案本身，選擇「加入」->「現有項目」。選擇要嵌入的文件（例如 config.txt、image.png 等）。
  2. 設定檔案為內嵌資源，在專案中選擇該文件，然後在屬性面板中將「生成動作」設置為「內嵌資源」。這樣，該文件就會作為內嵌資源添加到編譯的程序集內。
  3. 將 System.Reflection 添加到程式碼中，以便能夠訪問內嵌資源。

# 如何取得資源名稱

內嵌資源的名稱遵循一定的命名規則。通常，它們的命名格式為：命名空間。資料夾名稱。檔案名稱，其中每個層級由點（.）分隔。例如，假設有一個 config.txt 文件位於 MyApp.Resources 資料夾下，則其內嵌資源的名稱應為 MyApp.Resources.config.txt。

# 如何讀取內嵌資源

內嵌資源可以通過 Assembly.GetManifestResourceStream 方法來讀取。這樣可以將內嵌資源以流（Stream）的形式獲取，並且可以使用 StreamReader 等類型來處理文件內容。
