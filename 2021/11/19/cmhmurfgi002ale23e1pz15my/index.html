# C 語言 - 型別

C 語言的物件就是記憶體裡的某個位置，有名稱的物件也被稱為變數，物件的型別決定大小及編碼方式。

函式型別，說明函式介面，其他型別也可以用函式指定。

char 型別也是標準整數型別，會自動用不同方式解讀。

sizeof (型別)、sizeof 運算式、其型別為 size_t

# void 型別

void 型別，意思為無值可用

指向 void 的指標，指標型別 void * 代表物件的位置，前面有提到另一個東西也代表物件的位置，void * = 物件的位置 = 記憶體裡的某個位置
不須明確的型別轉換，可以隨意指定。

不同型別轉換順位，越大的優先度越高，但浮點數又優先於整數

# 陳述式

運算陳述式

區塊裡宣告的名稱將具有區塊範圍，若未宣告成 static 或 extern 的變數儲存空間，會自動在結束時釋放。

迴圈陳述式 : while、do…while、for
選擇陳述式 : if、switch
跳躍陳述式 : break、countinue、goto、return

# 藉值 (址) 呼叫

C 本質為藉值呼叫優點可兼容各種型別，但是若是複製大型資料則會花費大量資源，且函式無法修改原始資料。

白話文解釋差異
原始資料 => 產生副本 => 傳遞副本位置
原始資料 => 傳遞原始位置

就算只是讀取不修改，傳址仍高效於傳值。

# K&R 風格函式

在早期 Kernighan-Ritchie 標準，函示參數名稱與他們的型別宣告式各自分開。這種風格被稱為 K&R 風格或老派風格，雖然編譯器支援，但不應該繼續使用。
