PLX9x5x PCI Driver 學習筆記

發表於2022-01-02|更新於2025-12-22

# 驅動程式如何辨識裝置？

從 pci9x5x.inx 的 DeviceId 進行判斷，
裝置管理員 => 該裝置 => 詳細資料 => 硬體識別碼 (相容識別碼)，
電腦會自動判斷名稱是否符合，若符合就執行此驅動程式。

# 如何手動安裝驅動程式？

裝置管理員 => 該裝置 => 驅動程式 => 更新驅動程式 => 瀏覽電腦上的驅動程式

目標資料夾中應該要有 cat 、 inf 、sys ，如果沒數位簽章，那就需要啟動 WIN 測試模式，不然會無法安裝驅動程式。

# 驅動程式錯誤導致電腦無法開機該如何處理？

  • 長壓電源關機，使用安全模式開機，移出異常驅動程式。
  • 移除硬體，裝置管理員顯示隱藏驅動，移出異常驅動程式。

# PLX9x5x 做了哪些事？

處理 PnP 和電源事件、註冊設備介面、硬體資源映射、DMA 介面。

驅動程序初始化入口點，該入口由系統直接調用。
WDF_DRIVER_CONFIG_INIT( &config, PLxEvtDeviceAdd );
使用 config 初始化驅動配置結構，該數值是由硬體裝置提供，例如 EEPROM 讀出，該動作會自動完成，直接使用就可以。

# PLxEvtDeviceAdd

這裡驅動程序會註冊所有 PNP、電源、Io 回調、註冊接口和分配其他設備所需的軟件資源。

為函數設置回調，像 PCI 就會需要參考硬體進行資源配置。

# PLxEvtDevicePrepareHardware

當設備啟動或重新啟動時，執行設置設備所需的任何初始化，設置 DMA 通道或映射任何 I/O 端口資源。

WDFCMRESLIST   ResourcesTranslated 是 PnP 資源與設備，WDFCMRESLIST 是資源清單，內部包含 PCM_PARTIAL_RESOURCE_DESCRIPTOR，

# PLxPrepareHardware

獲取驅動分配的硬體資源，並將其映射到系統地址空間，簡單來說就是分配 BAR ( Base Address Register)。

desc 必須由 WdfCmResourceListGetDescriptor (ResourcesTranslated, i) 初始化，ResourcesTranslated 必須先初始化 desc 才能使用，WdfCmResourceListAppendDescriptor (ResourcesTranslated, desc); 個人測試無法成功無中生有產生 PCI BAR。

# PLxEvtDeviceReleaseHardware

在設備停止時調用，取消在 PLxEvtDevicePrepareHardware 中產生的資源。devExt 如果判斷有資源，就下 MmUnmapIoSpace 簡單明瞭。

# PLxEvtDeviceD0Entry

進入 D0，PLxInitWritet 初始化 Dma 數據結構。

# PlxEvtDriverContextCleanup

釋放在 DriverEntry 中分配的所有資源。

# PLX9x5x 還有哪些功能？

在 Public.h 中定義，此 IOCTL 切換驅動程序的 DMA 傳輸要求，每次調用時打開和關閉。

PLxEvtIoDeviceControl

收到設備請求後立即調用，請注意此功能會執行讀取與寫入，這在本示例是可以接受的，但您使用時可能需要某種程度的修改。

在 Control.c 的 PLxEvtIoDeviceControl 中把 IoControlCode 塞進 switch，然後該做什麼就做什麼，要增加功能只要在此加入。
