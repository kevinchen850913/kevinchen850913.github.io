Windows debugger - WinDbg 使用筆記

發表於2022-01-25|更新於2025-02-12

WinDbg 是微軟發布的 Windows debug 工具，這套軟體的功能是幫 Windows 除錯，從作業系統的角度來排除問題，除了排除作業系統本身的問題外，在處裡某些較為底層的軟體也會有奇效，如果軟體出現牽涉到電腦硬體相關的錯誤，或是踩到作業系統本身的地雷，就會用到這個神器，不過畢竟 Windows 都被暫停了，所以該套軟體必須要有兩台電腦搭配使用，一台是出事了的電腦，另一台安裝 WinDbg 用來檢測出問題的電腦，注意連線之前應確認勿連線多個網段，避免無法連線。

名詞解釋

  • Host Computer : 安裝除錯器的電腦。
  • Target Computer : 安裝待測驅動程式的電腦

# 設定 Target Computer

開啟 command line 輸入下列指令

hostip : Host Computer 的 IP address 要看仔細，注意不是使用 Target Computer，在 Host Computer 中的 Command Line 輸入 ipconfig 即可看到相關的資訊。

  • port : 可設定範圍 49152 到 65535 。
  • key : 若未指定則系統自動產生。
  • 範例中為 : 49152 + aaa.bbb.ccc.ddd

# 設定 Host Computer

Host Computer 中啟動 WinDbg , 選擇 Kernel Debug 模式。

重啟 Target Computer，重啟電腦時會發現無法進入 Windows ，會一直卡在開機畫面轉圈圈，此時必須由 Host computer 啟動 Windbg 才能解除該狀態，成功連接後 Windows 才會繼續執行。

現在已將成功地讓 Windows 進入 debug 狀態，此時 Windows 可以跟 IDE 除錯時用相同的方法來除錯，例如下方的範例中在程式插入中斷點，當程式碼執行到該位置，出現紅字時 Windows 被暫停，此時即可使用記憶體中的資料來協助排除問題，或是逐行執行來縮小問題的範圍。
