# BMC 是什麼 基板管理控制器（BMC）是一種小型專用處理器，主要用於遠端監控和管理伺服器或其他主機系統。BMC 通常基於 ARM 架構的系統單晶片（SoC），並內建圖形處理和邏輯控制功能。它一般安裝在電腦、伺服器、網路設備或儲存裝置的主機板上，並可透過專用或共用網路進行遠端存取。 BMC 具有多個連接介面，能夠通過感應器、快閃記憶體（如 BIOS/UEFI）來監控硬體狀況。它還可以透過序列接口或實體／虛擬 KVM（鍵盤、顯示器、滑鼠）來提供主控台存取權限，並記錄主機的事件和電力循環日誌。 # BMC 的主要功能 BMC（基板管理控制器）具備多項遠端管理和監控功能，以下是其主要功能： 遠程電源控制（開關電源 / 重啟 / 狀態監控） 用戶可以遠端開啟、關閉或重啟伺服器，並且監控伺服器的電源狀態。 串口重定向（Serial over LAN, SOL） 允許透過網路對伺服器的串口進行遠端重定向，使使用者可以像直接連接到伺服器的串口一樣進行操作。 KVM / 虛擬化管理（KVM/VM） 提供虛擬鍵盤、顯示器和滑鼠（KVM）功能，遠端控制伺服器，即便伺服器的操作系統無法啟動，仍可進行管 ...
