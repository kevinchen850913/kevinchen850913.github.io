Git Error 不是命令，也不是可用程序

發表於2024-03-09|更新於2025-08-08

當你完成了 Git 的安裝後，若命令提示符仍顯示 “不是內部或外部命令，也不是可運行的程序”，那可能是環境變數配置有問題。

# 異常原因

CMD 找不到 Git 或是 Git 功能出現異常，第一步要找出 Git 安裝路徑，通常預設安裝路徑如下，並嘗試以管理員權限開啟 git-cmd.exe、git-bash.exe，確認路徑位置有 Git 資料夾，然後確認 Git 本體的功能正常。

然後輸入 git --version 來確認 Git 是否正確安裝並能夠被識別。如果以上步驟未能解決問題，建議重新安裝 Git，你可以從 Git - Downloads 下載對應版本進行重新安裝。

# 解決方法

將 Git 添加到環境變數，在編輯環境變數窗口中添加以下兩個路徑。

  1. CMD 下命令 sysdm.cpl 開系統環境變數
  2. 在系統屬性窗口中，點擊高級標籤，再點擊環境變數按鈕。
  3. 在系統變數區域找到名為 Path 的變數，選中它後點擊編輯按鈕。
  4. 在編輯環境變數窗口中，點擊新建然後添加個路徑。
  5. 點擊確定保存所有更改，建議改完後電腦要重新開機。

若對於設定環境變數仍有疑問可參考 如何設定 WIN10 環境變數。
