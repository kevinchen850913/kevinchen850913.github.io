Git Error 副本失敗 clone The project could not be found

發表於2024-03-30|更新於2025-03-28

Git Clone 失敗，顯示 Git 無法找到指定的 repository。可能的原因包括 URL 錯誤、repository 已經被刪除或移動、你沒有訪問該 repository 的權限。

# 重新設定個人資料

確認 URL，確保 repository URL 正確無誤。檢查權限，確保你有足夠的權限來訪問該 repository，測試刪除使用者的個人資料。

配置文件權限錯誤，這個錯誤表示你沒有足夠的權限去修改全局的 Git 配置文件。這可能是因為你沒有以管理員身份運行命令提示符。

以管理員身份運行命令提示符，在開始菜單中找到命令提示符，右鍵點擊選擇「以管理員身份運行」，然後再次嘗試執行命令。檢查文件權限：確保你對 C:/Program Files/Git/etc/gitconfig 文件擁有寫入權限。

# SSH 代替 HTTP

另一種處理問題的方式是使用 SSH 連接，這也是一種常見的解決方法，如果 HTTP 協議存在問題，可以嘗試使用 SSH 協議進行 clone。這需要你設定 SSH 鍵並配置 GitLab。

更新 Git 認證，有時候 PC 已經註冊了其他用戶名和密碼，可以通過更新 TortoiseGit 或 Git 的認證來解決問題。在 TortoiseGit 中，你可以在「設定」→「網路」中選擇 SSH 客戶端來更新認證。
