Git Error 路徑保護 clone invalid path

發表於2024-03-23|更新於2025-02-06

在 Windows 上 clone 內核某分支源碼時報錯。

# 異常原因

在 NTFS 檔案系統中，存在一個路徑保護機制，防止某些不合法或潛在會導致檔案系統出錯的檔案路徑被創建或使用。這種機制可能會對 Git 操作中的某些路徑造成影響，特別是當這些路徑含有特殊字符或不符合 NTFS 文件系統規則時。

# 解決方法

關閉 NTFS 路徑保護機制，使用以下 Git 命令來關閉 NTFS 路徑保護機制，此命令將告訴 Git 忽略 NTFS 路徑保護機制，允許使用這些被認為是不合法的路徑。

重新嘗試 clone 操作，關閉保護機制後，重新進行 clone 操作或其他 Git 操作，確認問題是否得到解決。如果還是報錯，請檢查是否有其他潛在的檔案系統或路徑問題。
