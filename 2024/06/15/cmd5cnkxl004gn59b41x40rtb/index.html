使用 devtool search aspeed 找出 aspeed (kernel recipe)

# devtool modify (失敗)

利用 devtool modify 指令取得 linux-aspeed 程式碼，確認工作區的狀況。devtool modify linux-aspeed 失敗紀錄

# python KeyError

修正錯誤 python KeyError 錯誤訊息如下

修正檔案 openbmc\poky\scripts\lib\devtool\standard.py。

git diff 比較差異

# devtool modify (成功)

devtool modify linux-aspeed 成功紀錄

# 建置 linux-aspeed

修改 aspeed-ast2600-evb.dts (disable i2c bus 15)
檔案位置 openbmc\build\evb-ast2600\workspace\sources\linux-aspeed\scripts\dtc\include-prefixes\arm\aspeed\aspeed-ast2600-evb.dts

# devtool build

單獨建置 devtool build linux-aspeed

# devtool build-image

專案建置 devtool build-image obmc-phosphor-image

確認 appends\linux-aspeed_git.bbappend

# 提交 linux-aspeed

# git status 確認差異

以上的操作都在 workspace 中進行，接下來要把修改內容推送回原來的位置，會使用一些 git 的命令。

# git add 加入暫存區

git add arch/arm/boot/dts/aspeed/aspeed-ast2600-evb.dts

# git commit 提交更新

git commit -m “Disable i2c bus 15”

# devtool finish 確認結果

commit 後才能 devtool finish
devtool finish linux-aspeed meta-aspeed

確認 patch 檔案內容
cat meta-aspeed/recipes-kernel/linux/linux-aspeed/0001-Disable-i2c-bus-15.patch
