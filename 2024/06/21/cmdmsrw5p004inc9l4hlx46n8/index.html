OpenBMC(8)-Devtool_NewRecipe

發表於2024-06-22|更新於2025-07-28

# 建立新的層 (Layer)

New Recipe and New Layer 在專案中產生新的 Layer
bitbake-layers create-layer meta-helloworld

bitbake-layers add-layer meta-helloworld

可以看到 openbmc 資料夾中多了 meta-helloworld

# 建立遠端專案副本

從 github 副本遠端的 helloworld 專案，執行指令後，devtool 會根據 $source_tree 在指令執行的位置建立一個新資料夾，同時也創建了「workspace」資料夾。devtool 會將「workspace」資料夾作為一層加入 bblayers.conf 中。 $fetch_URI 中的原始碼將下載到 $source_tree 資料夾中。

evb-ast2600 中的 bblayers.conf 多了 meta-helloworld，資料夾中也多了該檔案。

workspace 中增加了 meta-test-helloworld_git.bbappend

# 修改 .bb 檔案 (Recipe)

檔案位置 openbmc\build\evb-ast2600\workspace\recipes\meta-test-helloworld

追加支援 c 的方法，使專案被執行，不會直接被跳過。

  • TARGET_CC_ARCH += “${LDFLAGS}” 是為了防止 GNU_HASH 錯誤。
  • $CC = gcc ， $cc f.c -o f ，意思是 gcc 編 f.c 後輸出 f 檔案。
  • log 的檔案位置 openbmc\build\evb-ast2600\tmp\work\armv7ahf-vfpv4d16-openbmc-linux-gnueabi\meta-test-helloworld\1.0+git\temp

# 建置 helloworld 專案

devtool build meta-test-helloworld

如果建置成功，在 openbmc\build\evb-ast2600\meta-test-helloworld 就會看到 helloworld 的二進制檔產生，沒有任何的副檔名，成功後建制整個專案。

# 使用 Layer + Recipe 機制合併專案

加上 -f 解決，到此完成 Layer 的修改流程。
git add meta-helloworld
