OpenBMC(1)-1stBuild

發表於2024-05-04|更新於2025-07-16

# 準備作業

取得 openBMC github 上的原始碼，在 GitLab 上建立 OpenBMC 的副本。依照 openBMC 中的 README.md 建構影像檔。

# SSH 遠端 server 方案

測試 Build server 權限已啟動可以成功登入。

檢查 Build server 上的遠端。

將 Build server 上的遠端改成 GitLab OpenBMC，遇到問題調整一下設定。

# 本地 Ubuntu 方案

根據 Yocto Doc 的說法，每個作業系統環境都有要求。 如果我們使用 Ubuntu，需要按照以下命令來安裝軟體包。

下載 openbmc 原始碼，然後移動至 openbmc。

# Build openbmc

第一步 Target your hardware 根據您的硬體目標設定環境。
OpenBMC(3)-setup_Script

儲存庫的根目錄中有一個特殊的腳本，可用於根據需要配置環境。
該腳本稱為 “setup” 並採用您的硬體目標的名稱作為參數。
如果不帶參數運行，將顯示支援的硬體目標。

按照文件操作下這個指令，設定目標機 evb-ast2600。

第二步使用 bitbake Build openbmc

虛擬機 CPU 100% 只給一核會跑很久，第一個檔案就載了五分鐘，所以改用 Build server，下方為網路太差可能產生的錯誤。
https://github.com/openbmc/openbmc/issues/3648

不知道是不是網絡不穩，下載檔案時總是出現失敗，網路上下載 .tar 檔案並解壓縮，可大幅減少建置時間。

解壓縮後出現 downloads 資料夾。

將配置檔的下載路徑修改為該位置，或是將解壓縮的檔案放到預設的下載路徑，使其免去重新下載的工作。

重新下建置指令，即可成功產生檔案。

產生二進位檔案的位置。
