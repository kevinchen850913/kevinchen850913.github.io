OpenBMC(2)-QEMU

# 準備作業

  • QEMU 是一種虛擬機，可支援用來搭建 OpenBMC。
  • 必須先完成 OpenBMC(1)-1stBuild 並取得可用的二進位檔。
  • 使用 QEMU (Quick Emulator) 來模擬系統上閃爍的影像。
  • 在不同架構上進行快速測試、偵錯和驗證應用程式 / 特性 / 功能

# Windows 中使用 QEMU

QEMU 是一種虛擬機，可支援用來搭建 OpenBMC。
QEMU 下載 https://www.qemu.org/download/#windows
Windows 版 QEMU 是實驗性軟體，甚至可能包含嚴重的錯誤，因此使用二進位檔案需要您自擔風險。根據你的作業系統，QEMU 的目錄可能會有所不同。

  • Ubuntu $BUILDDIR/$MACHINE/tmp/work/x86_64-linux/
  • iOS $BUILDDIR/$MACHINE/tmp/work/aarch64-linux/

# QEMU 中運行 OpenBMC

移動至本地位置 cd /d D:\\qemu ，開始執行 qemu。

# 登入 qemu bmc

登入 bmc => Username /password: root / 0penBmc
離開 qemu => Ctrl + a + x
Web login  https://localhost:2443

# QEMU 指令說明

教學中使用的命令如下

  • m: 仿真機的記憶體大小。
  • M: 要模擬的機器類型。
  • nographic: 停用圖形輸出並將串列 I/O 重定向到控制台磁碟。
    • file: 在此輸入您的圖像名稱。
    • if: 檔案副檔名類型，例如 : .mtd。
    • format: 原始資料檔案。
  • net nic: 置或建立板載 NIC 並將其連接到集線器 0。
  • net user: 初始化一個主機網路介面。
    • hostfwd: 將客戶端連接埠轉送到主機連接埠。

筆記：

  1. 不同的參數 (例 : -m、-M) 之間以空格分隔。
  2. 參數的子參數 (例：檔案、格式) 之間以逗號分隔。
