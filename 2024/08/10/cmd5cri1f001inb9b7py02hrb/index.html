發表於2024-08-10|更新於2025-07-16

# aspeed-pfr-tool

BMC UART 下 aspeed-pfr-tool 指令即可使用 AST1060 的功能。
aspeed-pfr-tool 圍繞著 Intel SMBus 的規範設計，實作主要是在 AST1060 的程式碼，雙方搭配才能使用，aspeed-pfr-tool 就像是 Intel SMBus 的範例程式。

PFR 的三項核心功能都放在 write_reg，這份筆記 aspeed-pfr-tool 可以優先看這一段，其他用到再來查。

檔案位置 : project\openbmc\meta-aspeed-sdk\meta-ast2600-pfr\recipes-aspeed\aspeed-pfr-tool\aspeed-pfr-tool，aspeed-sdk 中其實就只有 aspeed-pfr-tool。

# pfrtoolconf

# provision show

provision 這個指令有三種用法 show 、lock、file，主要功能是保護金鑰。

完成 AST1060 的配置後，觸發重置，這將使用新配置的資料觸發 AST1060 身份驗證過程。下次啟動時，在驗證系統配置完成並確認 ASPEED PFR 狀態後，應發送訊息以鎖定 AST1060 UFM，以保護配置的金鑰免於任何進一步修改。這樣就完成了 ASPEED PFR 的設定。 鎖定命令後，UFM 中的設定資料被寫入保護，並且韌體透過 SMBus 郵箱停用 BMC 和 BIOS 寫入命令。

PFR 規範說明要停用 UART 啟動。
系統鎖定後，應停用韌體旁路功能和從 UART 啟動功能，以避免安全性問題。

方法位置 openbmc\meta-aspeed-sdk\meta-ast2600-pfr\recipes-aspeed\aspeed-pfr-tool\aspeed-pfr-tool\provision.c

# checkpoint

BMC 狀態，僅允許從 BMC 寫入，直到 BMC 發出啟動完成訊號，搭配的功能在 AST1060 的程式碼中，而非 AST1060 的規格手冊，所以這些指令都是配合 Intel 的規範寫在程式中，而其他廠商則可能使用不同的位置與方法。

方法只支援 1、7、8、9。

MB_CHKPT_START、MB_CHKPT_PAUSE、MB_CHKPT_RESUME、MB_CHKPT_COMPLETE

方法位置 openbmc\meta-aspeed-sdk\meta-ast2600-pfr\recipes-aspeed\aspeed-pfr-tool\aspeed-pfr-tool\checkpoint.c

這些回傳資訊會在 AST1060 的程式碼中使用

workspace\aspeed-zephyr-project\apps\aspeed-pfr\src\Smbus_mailbox\Smbus_mailbox.c

aspeed 的狀態機也會確認其他裝置的狀態，或是去攔截一些異常行為。

workspace\aspeed-zephyr-project\apps\aspeed-pfr\src\AspeedStateMachine\AspeedStateMachine.c

Secure Update For BMC

  1. Get bmc_signed_cap.bin from aspeed openbmc sdk build folder. Path is ./build/${machine}/tmp/deploy/images/${machine}/pfr_images
  2. Put bmc_signed_cap.bin to bmc’s staging partition e.g.
    # flashcp -v /tmp/bmc_signed_cap.bin /dev/mtd9
  3. Run aspeed pfr tool on BMC console:
    # aspeed-pfr-tool -b 4 -w 0x13 0x08

Secure Recovery For BMC

  1. Get bmc_signed_cap.bin from aspeed openbmc sdk build folder. Path is ./build/${machine}/tmp/deploy/images/${machine}/pfr_images
  2. Put bmc_signed_cap.bin to bmc’s staging partition e.g.
    # flashcp -v /tmp/bmc_signed_cap.bin /dev/mtd9
  3. Run aspeed pfr tool on BMC console:
    # aspeed-pfr-tool -b 4 -w 0x13 0x10
  4. Recovery will be performed after BMC and PCH bootup successfully. Send the following mailbox commands to simulate system boot completed in BMC console
  • If using Intel-pfr solution:
    # aspeed-pfr-tool -b 13 -a 0x70 -w 0x11 0x1
    # aspeed-pfr-tool -b 13 -a 0x70 -w 0x11 0x9
    # aspeed-pfr-tool -b 13 -a 0x70 -w 0x11 0x9
  • If using AMD solution:
    # aspeed-pfr-tool -w 0xf 0x9
    # aspeed-pfr-tool -b 13 -a 0x70 -w 0x11 0x9
