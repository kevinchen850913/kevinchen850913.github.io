發表於2024-08-17|更新於2025-01-14

# AST1060 規格書

Firmware SPI Memory Controller (BSPI)
此 SPI 控制器提供 2 個片選引腳 (CE0 ∼ CE1) 來控制最多 2 個快閃記憶體元件。 CE0 ∼ CE1 可以透過可程式分配到不同的不重疊且連續的位址區域起始 / 結束位址。 允許的快閃記憶體位址空間為：0x8000 0000 ∼ 0x8FFF FFFF

# 開機恢復功能（ABR）

  • 備用啟動復原功能由 strap OTP trap en bspiabr 啟用。
  • 當韌體啟動成功後，應停用 FMC WDT2 以停止啟動開關。
  • 啟動切換的預設過期時間設定為 22 秒。 如果韌體啟動時間長於
    22 秒，應該更改過期時間並在 22 秒內重新開始計數。
  • 支援 2 種模式的交替啟動功能：
    1. 使用 2 個 SPI 快閃記憶體零件，CE0 和 CE1。 CE0 是主要啟動來源，並從 CE1 備用啟動。對於此引導模式，閃存大小資訊是可選的。
    2. 使用 1 個 SPI 快閃記憶體部分，CE0。 將快閃記憶體空間均勻分割為大小相同的 2 部分。 下隔板是預設引導區，並且從上分區交替引導。此引導模式需要快閃記憶體大小資訊。
  • FMC WDT2 逾時後，將重設 CPU 並在 2 個代碼區域之間切換啟動來源。第二啟動功能將繼續運行，直到韌體停用它。
  • 當使用 2 flash 模式並從 CE1 flash 啟動時，此時 CE0 和 CE1 的位址會對應為交換了。 若要恢復位址映射，韌體應清除 FMC64.bit [4] 處的引導選擇標誌。
  • 當使用 1 flash 模式並從上分割區啟動時，此時下方分割區和上分割區的位址對映會交換。 若要恢復位址映射，韌體應清除 FMC64.bit 處的引導選擇標誌。
  • CE1 快閃記憶體中的韌體代碼可以與主快閃記憶體相同。

# 地址模式檢測功能

  • 位址模式 3B/4B 切換功能由 strap OTP trap en bspiadrswap 啟用。
  • Flash 控制器具有與韌體配合偵測 SPI Flash 位址模式的能力。
  • 它使用一個看門狗定時器 FMC WDT1，過期時間為 2 秒，並在 CPU 啟動時啟用。如果韌體可以正常執行，則該看門狗計時器將在很早的階段被韌體停用。如果定時器逾時，CPU 將被重位，SPI 位址模式將從 3B 切換到 4B 或從 4B 切換至 3B。
  • 此操作最多重複 2 次，然後停止。 這意味著韌體可能有出現問題，無法正常開機。
  • 此操作僅適用於引導閃存 CE0。

# 無縫更新功能

無縫更新允許更新主機固件，而無需重置系統。 在無縫更新過程中，AST1060 將 BMC 和 PCH spi mux 從 BMC/PCH 切換到 AST1060 以處理韌體更新。 BMC 和主機韌體必須確保 spi 快閃存在無縫更新過程中不會被存取。

無縫更新膠囊應包含韌體磁碟區清單 (FVM)，PCH 活動快閃記憶體應包含 PFM 區域中的新 PFM+FVM 佈局。 在韌體驗證過程中，如果 PCH 活動快閃記憶體包含 FVM，AST1060 會驗證 PFM 和 FVM 區域。

# VERIFY_FAILED

SPDM = Security Protocol and Data Model
安全協定和資料模型

DMTF = Distributed Management Task Force

DMTF 標準包括：

  • CADF - 雲端稽核資料聯合
  • CIMI - 雲端基礎設施管理接口
  • CIM - 一般資訊模型
  • DASH - 系統硬體的桌面和行動架構
  • MCTP - 管理組件傳輸協議，包括 NVMe-MI™、I2C/SMBus 和 PCIe® 綁定
  • NC-SI - 網路控制器邊帶接口
  • OVF - 開放虛擬化格式
  • PLDM - 平台級資料模型，包括韌體更新、Redfish 設備支援 (RDE)
  • Redfish – 包括協定、架構、主機介面、設定檔
  • SMASH - 伺服器硬體的系統管理架構
  • SMBIOS - 系統管理 BIOS
  • SPDM - 安全協定與資料模型
