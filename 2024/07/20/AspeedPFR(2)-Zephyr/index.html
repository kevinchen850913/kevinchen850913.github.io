# Zephyr 簡介

Zephyr 專案是一個可擴展的即時作業系統 (RTOS)，支援多種硬體架構，針對資源受限的裝置進行了最佳化，並在建置時考慮了安全性。Zephyr OS 基於小佔用內核，設計用於資源受限的系統：從簡單的嵌入式環境感測器和 LED 穿戴式裝置到複雜的智慧手錶和物聯網無線網關。

AspeedPFR 的專案會使用 Zephyr 來建置，所以必須先完成 Zephyr 環境的搭建，Ubuntu、Windows 的環境我都有成功搭建，Ubuntu 的建置難度較低，不過考量到可能會使用到 Zephyr 的 dbg 支援裝況，我在本地的 Windows 上也搭建了開發環境， Zephyr 網站教學完整，可參考文件 Getting Started Guide — Zephyr Project Documentation。

# 安裝 Zephyr (Ubuntu)

  1. 依照 Zephyr 網站教學操作安裝在 Ubuntu 虛擬機
  2. 啟動虛擬環境： source ~/zephyrproject/.venv/bin/activate ，啟動後，您的 shell 將以 (.venv) . 可以透過運作隨時停用虛擬環境  deactivate 。每次開始工作時都啟動虛擬環境。
  3. 要注意檔案位置，按照流程專案會處於 user 資料夾下。
  1. 安裝後產生的檔案 (Zephyr、SDK)。

# 安裝 Zephyr (Windows)

依照 Zephyr 網站教學操作安裝在 Windows，我在操作的過程中遇到不少問題，如果可以直接申請一台 Ubuntu 的電腦可以解決不少麻煩，也有可能是 MIS 的管理，才會東卡西卡。

# 安裝 Chocolatey

開啟白名單機制還是無法順利安裝 Chocolatey。

使用無管理員權限安裝法，可以手動安裝成功。
Chocolatey Software Docs | Setup / Install

安裝過程中跳出警告。

有些軟體安裝失敗。

# 補裝缺失軟體

手動補裝 git commandline

安裝後仍出現錯誤，檢查後發現 git 確實異常，再重裝一次看看。

確認 git 能正常使用，將兩個版本庫都加入遠端，這樣處理最方便。

移動至 Aspeed 長出的分支 v3.4.0。

  • 補裝 GNU Wget 1.21.4 for Windows，選擇 32 位 / 64 位，下載 ZIP/EXE，將下載下來的 EXE 檔案放到 C:\Windows\System32 即可正常使用。
  • 補裝 CMake，記得要加入環境才能正常使用，還有要重開 cmd。
  • 加入 7z 的環境變數，不然無法使用腳本解壓縮。
  • 所以缺失檔案我都直接手動加入環境變數，下圖提供安裝成功後的環境變數範例，下次換環境的時候可以照著填寫。

# Zephyr ast2600

Zephyr 其實可以建 ast2600 的檔案，不過下一個章節會使用 openbmc 建置，而不會採用 Zephyr 的方案，因為在未來 openbmc 可以移植至各種 BMC IC，才不會被 AST2600 綁架。

# GitHub Aspeed-Master

v09.00 是從 openbmc 的 2.13.0-dev 長出，但並非是最接近的版本，經過程式碼統合分析，粗判最接近的版本為 2.14.0，這意味著 Aspeed 的分支並非只有 Aspeed 製作的內容，而是會密切的、多次的、小規模的合併 openbmc 主線，另外其他廠商的分支 Aspeed 也會嘗試整合，不過這客製化的工作無法反映至 git 的版本，簡單來說 Aspeed 分支中包含著一些未對外公開的分支。
