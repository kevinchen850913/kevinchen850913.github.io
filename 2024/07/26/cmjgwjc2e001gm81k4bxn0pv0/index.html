DC-SCM Rev2.0 模組整合 Axiado 的創新 TCU 與人工智慧（AI）/ 機器學習（ML）功能，包括基板管理控制器（BMC）、平台信任根（PRoT）、可信任平台模組（TPM）和複雜的可程式化邏輯裝置（CPLD）等關鍵功能，從而實現基於單晶片的 DC-SCM 解決方案。

# AST1060 DC-SCM EVB

  • ASPEED DC-SCM 2.0 模組卡
    DC-SCI 0.95l 腳位排列，DC SCM v0.7 規格
  • DC SCM 2.0 基板
    模擬 CPU/PCH SPI/eSPI 主機（例如 SF 600 排針類比 QSPI 主機）
    用於 BMC 測試的 I3C/I2C 主機 / 裝置介面。
    橋接 LVDS I/O 介面、PCIe EP 和 RC 連接埠以及用於 BMC 功能測試的 NCSI 網路卡。
  • FPC 排線：橋接 DC-SCM 模組介面到 SCM DBG 板
  • 調試板：預留 LTPI-FPGA、BMC、BIC、PFR、SPI flash 調試和程式設計接口。

# AST1060 IC

# AHB Bus Controller (AHBC)

AHBC（AHB 總線控制器）是一個高效能的匯流排控制器，主要負責管理 ARM CPU 與週邊裝置之間的通訊。它包含了一些關鍵的功能來確保匯流排的運作順利。首先，AHBC 有一個優先權仲裁器，這個仲裁器透過循環的方式來決定哪一個匯流排主控器有權限存取 AHB，確保每個主控器都能公平地存取總線。每個主控器都有自己的請求 / 授權介面來與仲裁器進行互動。除了仲裁器，還有一個位址解碼器，這個解碼器的作用是負責將資料精確地導向到正確的位置。

AHBC 還有一些新增的功能，像是重映射機制，它能夠加快程式碼的存取速度，提升整體效能。此外，AHBC 還提供了日誌緩衝區的功能，這個緩衝區可以用來記錄特定位址的讀寫資料，對於韌體調試特別有幫助。這些日誌資料可以存放在 DRAM 或 SRAM 中，緩衝區的大小可從 4KB 到 1MB，讓開發者能夠輕鬆地監控和調試系統的行為。

# 燒錄專用軟體

Uart_FW_v20116 這是工具包，內有包含使用手冊

  • uart_fw_user_guide_v20116.pdf
  • boot_from_uart_hdr_py.exe
  • uart_fw_py.exe
  • uart_fw_py_gui.exe

以 AST2600 EVB 為例，以下是實作 uart_fw 實用程式的步驟。

  1. 關閉設備電源。
  2. 將 UART 電纜連接到 BMC UART。 （如果 BMC 控制台已打開，請將其關閉）
  3. 啟用「從 UART 啟動」外部帶。 請參閱 “板或引腳設定” 部分。
  4. 執行 uart_fw 實用程式命令。
  5. 打開設備電源。 （此步驟應在上述步驟之後執行）
  6. uart_fw 實作 flash 讀取、擦除或寫入操作。
  7. 拆下「從 UART 啟動」外部帶子並開啟 / 關閉設備的交流電。

SPI: Select SPI controller. It could be SPI0(FMC) / SPI1 or SPI2.
CS: Select chip select. The limit of number is listed below. This item will be limited by HW designed.

FMC SPI1 SPI2
AST2600/AST2620 3 2 2
AST1030/AST1035 2 2 2
AST1060 2 N/A N/A

這張表的意思是 CS 支援數量會受到 SPI 影響。
例 : AST1060 在 FMC (SPI0) 中可以支援兩種 CS 狀態。
