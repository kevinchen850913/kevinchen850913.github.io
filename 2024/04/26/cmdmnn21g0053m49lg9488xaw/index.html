# 中文介面設定

中文介面的設定可以從右上角選擇地區 / 語言，按 Manage Installed Languages 找到中文 (繁體)。安裝完成後，回到地區 / 語言，將語言換成中文，重新開機後即完成語言替換。

# 硬碟空間耗盡

我在網路上找不到簡單的解決方案，花了不少時間才解決。問題可能與版本或環境相關，許多解決方法都需要使用一些較為特殊的手段，提供我覺得比較簡單的解決方法。

這個問題可以分為兩個主要步驟：
第一讓 VirtualBox 可以擴展硬碟空間。
第二讓虛擬機中的 Ubuntu 重新分配可用硬碟。
需要注意 Ubuntu 並不像 Windows 10 那樣自帶磁碟區延伸工具。

如果你使用的是較新版本的 VirtualBox，並且在設定硬碟時選擇了預設的動態可擴充硬碟，那麼只需根據下方圖片調整硬碟容量，即可完成第一步。

接著在 Ubuntu 上安裝 gparted 這套軟體。

打開應用程式，選擇指定硬碟 Resize 即可重新分配空間。
