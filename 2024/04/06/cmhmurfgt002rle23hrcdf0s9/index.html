Git Error 分支遺失 could not get HEAD hash

發表於2024-04-07|更新於2025-11-06

遠端分支消失或遠端標籤消失、拉取或推送到遠端失敗，無法開啟遠端的 log，並出現如下錯誤信息，這通常表示 Git 在處理遠端存儲庫時遇到了權限或安全性問題。以下是解決此問題的步驟。

# 檢查遠端分支的 HEAD

確認 HEAD 和 refs/heads/master 的內容是否正確，這些檔案通常位於存儲庫目錄的 .git/refs 路徑下。確保 HEAD 檔案內容是指向有效的分支名，如 refs/heads/master，並且 refs/heads/master 檔案內容是一個有效的 SHA-1 哈希值。

手動修復異常，如果發現 HEAD 或 refs/heads/master 內容異常，可以手動修復它們，提供一個正確有效的 SHA-1 哈希值。

# 檢查 Git 安全設置

在 Git 2.35.2 及以上版本中，Git 會檢查存取的存儲庫目錄是否為安全目錄。如果存儲庫目錄未被列入 GIT_CEILING_DIRECTORIES 環境變數或 git config 中的 safe.directory 設定，Git 會認為該目錄不安全，因此無法存取。
