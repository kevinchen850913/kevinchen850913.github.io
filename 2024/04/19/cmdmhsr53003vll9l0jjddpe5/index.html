Linux 基本指令介紹

發表於2024-04-20|更新於2025-07-28

# 常用的指令表

指令 說明
ls 列出資料夾與檔案名稱
pwd 顯示當下工作路徑
cd 變換工作路徑
mv 移動檔案
rm 刪除檔案
cat 列出檔案內容
cp 複製檔案
scp 在不同 Linux 主機間複製檔案
mkdir 建立資料夾
touch 建立檔案
vi 新增、修改、搜尋並取代文字
sudo 使用最高權限執行
man 查看指令說明文件
help 查看指令說明
clear 清除終端機上的訊息
which 查詢指令的來源路徑
find 尋找資料夾或檔案
exit 離開系統

# 檔案與目錄管理

# cd 變換工作路徑

  • cd … <== 回到上一層
  • cd <== 回到使用者目錄
  • cd / 桌面 <== 到 / 桌面 這一個目錄

# pwd 顯示當前目錄

# ls 顯示檔案名稱

  • ls 顯示檔案名稱
  • ls -l 詳細列出檔案系統結構
  • ls -a 顯示隱藏檔 （以”.” 開頭的檔案）
  • ls -al 同時顯示隱藏檔與詳細資料
  • ls -s 按照檔案大小排序
  • ls -t 按照修改時間排序

# cat 顯示檔案內容

# mkdir 建立目錄

語法: mkdir <新目錄名稱>

# rmdir 移除目錄

mkdir 是建立目錄，而 rmdir 就是移除目錄的指令。不過，若是欲移除的目錄裡頭有檔案或其他目錄存在，就無法移除，這時就要用剛剛的 rm -rf 來移除啦！

# touch 建立檔案

語法: touch <檔案名稱>

# rm 移除檔案

通常在 Linux 系統下，為了怕檔案被誤殺，所以都已經有 -i 這個參數， -i
是指每個檔案被殺掉之前都會確認一次。而如果要連目錄下的東西都一起殺掉的話，就要使用
- rf 這個參數。

# mv 移動檔案

語法： mv <來源檔或目錄> < 目的檔或目錄 > “.”
這個字當作目標時，可以將檔案移動至目前的工作目錄。

# cp 複製檔案

語法: cp <來源檔或目錄> < 目的檔或目錄 >

# scp 複製檔案 (遠端)

# 系統與網路命令

# sudo 管理員權限

暫時授予使用者管理員權限，安裝軟體時常常會用到。

# chown 改變擁有者

改變擁有者的指令， copy 檔案給別人後將檔案的擁有人改成對方。

# chmod 改變擁有群組

作用與 chown 相似，只是在改變的是擁有群組。

# man 查看指令說明

man 或 info 可以用來查詢的功能與說明。

# ifconfig 查看網路卡

查詢目前我們這個系統的網路卡的狀況

想想也是，改去查 Server 的網路卡。

# ping 要求對向回應

察看對方網路是否有動作，早期網路爛線常會使用這個功能。

# ssh 遠端連線

安全外殼協議 (SSH) 是一種加密 網路協議，用於在不安全的網路上安全地運行網路服務。 [1] 其最著名的應用程式是遠端登入和命令列執行。
