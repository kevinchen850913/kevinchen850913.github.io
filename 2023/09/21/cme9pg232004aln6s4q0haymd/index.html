Markdown 路徑覆寫工具

發表於2023-09-22|更新於2025-08-13

我習慣用 Markdown 來撰寫筆記，但文字之外的檔案並沒有找到合適的共款方案，而是隨著資料量逐漸累積，經年累月整份筆記變得越來越龐大，這讓我有個想法，就是要將文字與其他資料進行切割。

# 故事起因

我希望筆記庫只包含純文字，而其他資料如圖片、附件等則應該儲存在專門的資料夾或位置。這樣一來，不僅能讓筆記庫保持乾淨簡潔，也能提高資料管理的效率。然而，問題隨之而來，尤其是當需要跨工作區進行資料連結時，這樣的操作變得非常麻煩。

預設的相對路徑無法實現 md 檔與資料的有效分離，這意味著我必須依賴絕對路徑來處理這些資料，而這樣做往往會帶來更多的困擾。每次需要處理路徑的時候，不僅需要繁瑣的手動操作，還容易出現路徑錯誤，極大地浪費了我的時間和精力。

md 檔外部路徑的範例

逐步冒出的問題

  • 無法使用工具原生的索引
  • 無法動態更新路路徑
  • 相對路徑還是無法切割檔案
  • 路徑越長，遇到越多特殊字元
  • 引用越來越麻煩，我越來越懶

總之該來正視這個問題了，所以才有了這篇文章。

# 解決思路

在尋找工具前，先想像有可能得到什麼，也許微軟有提供原生的快捷建，只是我不知道，也許有成熟的工具，可以直接使用，也許有半套的腳本工具，需要自己編寫一部份程式，所以我先整理了目標的優先順序。

目標需求 (重要 => 可有可無)

  1. 剪貼簿的讀寫與修改
  2. 剪貼簿的文字正規化
  3. 修改的快捷方法
  4. 複製路徑的快捷方法

補充複製路徑的方法與我的想法
壓住 shift 同時右鍵檔案，即會出現複製路徑的選項。這個操作方式有夠卡手，右鍵開選單都已經夠麻煩了，還要押壓住 shift 才會出現，然後複製出的文字會被加上雙引號，對使用者又增加一層困擾。

# 尋找方案

遇到問題就是先餵狗，沒想到竟然沒有現成方案，可能是會這麼用電腦的人是小眾中的小眾，而且有能力自己解決，看來還是只能自己寫，反正能有多難，先做個垃圾，反正之後還能改。

  • 右鍵選單擴充工具，太肥大，而且早期軟體支援性堪慮
  • 滑鼠自訂巨集，能自訂義的部分太少，還是要自己寫
  • 微軟救救我，你確定？改預設功能要修改機碼喔

# 路徑覆蓋對策

你或許有聽過，絕對路徑就是絕對不要使用的路徑，切勿直接使用絕對路徑，要特殊處理成類似相對路徑，還有檔案不能改名、不能移動，這些必要之惡要有心理準備，所以在制定檔案名稱時要想清楚，最好只使用英文跟數字，避免使用特殊符號，造成自己的困擾。

使用絕對路徑的老方法，自訂環境變數或是捷徑，解決彈性不足的問題，而這是我採用的方法是網路硬碟的綽號，檔案放在 NAS 個人覺得這樣是最直觀使用的方法，本機 => 連結網路磁碟機 => 自訂某個槽用來當路徑。

# 工具使用範例

有一張想要貼到筆記中的照片或網頁上的圖片，對圖片選擇複製。

軟體檢測到剪貼簿出現圖片，會執行兩件事，首先會將圖片搬運至某個位置 (NAS 中的指定資料夾)，接著會取得新的檔案路徑並轉成 MD 的絕對位置外聯語法。

  1. C:\Users\kevin\Downloads\筆記使用的圖片.jpg
  2. Z:\NAS\kevin\筆記使用的圖片.jpg
  3. [筆記使用的圖片](Z:\NAS\kevin\筆記使用的圖片.jpg)

# 程式碼範例

確認物件功能撰寫讀寫測試，簡單測試 Clipboard 能否正常運作。

加上文字處理，為了避免特殊字元導致方法爆開，所以自己手動塞，到這部直接把應用程式綁在快捷鍵上，就能順利使用。

更進一步修改加上監察者，讓程式能在執行中就自動完成此工作，開啟程式後自動監看複製事件，若特定條件，則使連結自動修改再塞回剪貼簿，等我使用一段時間後再來分享心得。

實際應用有夠好用，想怎麼改就怎麼改，我後來還去修改了機碼，直接把功能綁到滑鼠右鍵選單，文書作業處理路徑時加速 100%，不過真的覺得修改機碼有夠麻煩。(微軟應該開放出來讓大家自己自訂)
