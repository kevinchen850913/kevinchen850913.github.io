C++ 學習筆記 - 數據結構(struct)

發表於2023-06-02|更新於2025-03-14

# 數據結構

數據結構是一組以同一名稱組合在一起的數據元素。

如何使用結構內的資料，使用 . 連接後，即可像聲明中的類型一般使用，例如 weight 的類型是 int，所可以進行計算。

因為結構是類型，所以它們也可以用作數組類型來構造。

# 指向結構的指標

結構可以通過其自身類型的指針指向。

混合指標和結構引入新的運算符：箭頭運算符 -> 。

表達式 功能 等同
a.b a 的成員 b ----
a->b a 指向的成員 b (*a).b
*a.b a 的成員 b 的指向 *(a.b)

# 嵌套結構

結構包含的元素也可以是結構。
