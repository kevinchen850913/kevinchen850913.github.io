BMC(3)-Yocto Project

發表於2023-11-25|更新於2025-01-14

# Yocto Project 簡介

https://www.yoctoproject.org/
Yocto Project 是大型協作項目，Linux 基金會下的組織，用於開發和建構嵌入式 Linux 系統的框架。Yocto Project 主要由三個元件組成 OpenEmbedded-Core，BitBake，PokyYocto ，其中 Project 與 OpenEmbedded 共同維護 OpenEmbedded Core 和 Bitbake 。

# Yocto 縫合範圍

https://www.yoctoproject.org/development/technical-overview/

  • Layer (層) : 相關食譜的集合。層可讓您整合相關元資料以自訂您的構建，並隔離多個架構建構的資訊。層在涵蓋先前規範的能力方面是分層的。您可以包含 Yocto 專案中任意數量的可用層，並透過在它們後面新增層來自訂建置。
  • Metadata (元資料) : Yocto 專案的一個關鍵元素是用於建立 Linux 發行版的元數據，包含在建置系統在建置映像時解析的檔案中。一般來說，元資料包括配方、設定檔和涉及建構指令本身的其他信息，以及用於控制建構內容和影響建構方式的資料。元數據還包括用於指示使用的軟體版本以及從何處獲取軟體的命令和數據，以及用於修復錯誤或自定義的軟體本身的更改或添加在特定情況下使用的軟體。OpenEmbedded Core 是一組重要的經過驗證的元資料。
  • Recipe (配方) : 最常見的元資料形式。配方將包含用於建置套件的設定和任務列表，然後將其用於建立二進位映像。配方描述了從哪裡獲取原始程式碼以及要應用哪些補丁。配方描述了庫或其他配方的依賴關係，以及配置和編譯選項。它們分層儲存。
    • Configuration Files (設定檔) : 保存變數的全域定義、使用者定義的變數和硬體設定資訊的檔案。它們告訴建構系統要建構什麼並將其放入映像中以支援特定平台。

# OpenEmbedded-Core

2011 年 3 月 OpenEmbedded 與 Yocto 計劃合作，以 OpenEmbedded-Core 專案作為項目發展的名稱。 專案包含 BitBake 使用的通用基礎元資料集，元資料由 layers 所組成包含 recipe、slayers 、 classes，此元資料在 OpenEmbedded 和 Yocto 專案之間共用。

  • OpenEmbedded 與 Yocto 共同維護
  • bitbake 建置工具和腳本
  • Metadata 與 configuration

# OpenEmbedded

Yocto 專案推廣的建置系統架構。OpenEmbedded 是一個採用 MIT 授權條款的軟體架構，目標在於為嵌入式系統構建 Linux 發行版。在舊的 OpenEmbedded-Classic 平台上，所有自動建置的處方 (Recipes) 都放在一起，而在新的 OpenEmbedded-Core，其結構由許多 layers 組成，讓使用者可以更容易加入客製化的自動建置處方，OpenEmbedded 與 Yocto 共同維護 OE 核心建置系統。

在我研究過後，Yocto 可以說是 OpenEmbedded 的超集，OpenEmbedded 專案重整後變成 OpenEmbedded-Core，且 Bitbake 也脫離成為獨立工具，目前 OpenEmbedded 的官方網站中並沒有支援 Yocto 之外的功能。

# Metadata

元資料由開發人員用來自訂系統建構的設定檔和指令組成。

  • 結構化的 recipes 集合，告訴 BitBake 要建構什麼，分層組織。

# Bitbake

https://docs.yoctoproject.org/bitbake/2.6/index.html
Bitbake 曾經是 OpenEmbeded 中的建置工具。BitBake 在 OpenEmbedded 專案中存在了一段時間，直到它被分離為一個獨立的、維護的、獨立於發行版的工具。BitBake 由 Yocto 專案和 OpenEmbedded 專案共同維護。

  • 強大且靈活的建置引擎 (使用 Python)
  • 讀取元數據 (組態檔與處方檔)
  • 確定依賴關係
  • 安排任務

meta(oe-core) => meta-poky => meta-yocto-bsp => Other layers
上述檔案一起送烤箱 (BitBake)，烤完後就會產生檔案。

# Poky

Poky 是 Yocto 專案參考發行版，Poky 包含一個版本的 bitbake 和 oe-core，您可以從中啟動您的專案。使用所有這些工具建立某些東西的起點，以便為您嘗試將它們組合在一起的特定事物建立圖像。

  • 參考布局
  • 使用 Yocto 專案建構事物的起點
  • 主要 Poky 層
  • 核心組件
    • Bitbake 工具：基於 python 的建置引擎
    • 建置腳本 (基礎設施)
    • 基礎包配方 (oe-core)
    • meta-poky (包含分發策略)
    • 參考 BSP (板支援包)
    • Yocto 專案文件 (配合的詳細資訊)
