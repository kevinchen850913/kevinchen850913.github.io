# AspeedTech-BMC/zephyr

https://github.com/AspeedTech-BMC/zephyr

AspeedTech-BMC/zephyr 是 zephyr 的 SDK，在 zephyr 中加入 AspeedTech-BMC/zephyr 可以獲得更多硬體版的支援，以及更多的範例程式。
https://github.com/AspeedTech-BMC/zephyr/tree/aspeed-main-v2.6.0/samples/boards/ast1060_evb

AspeedTech 的開發版範例程式放置位置。
Supported Boards — Zephyr Project Documentation

zephyr 的一些開發版支援文件，感覺沒更新資料有點過時。

# AspeedTech-BMC/aspeed-zephyr-project

https://github.com/AspeedTech-BMC/aspeed-zephyr-project

AspeedTech-BMC/aspeed-zephyr-project 是 zephyr 中的專案，用來支援下方的板卡，該專案需要搭配 zephyr 與 AspeedTech-BMC/zephyr 才能進行使用。

支援的板卡

  • ast1060_dcscm：具有 Intel 影像格式的 DCSCM
  • ast1060_dcscm_amd：具有 AMD 影像格式的 DCSCM
  • ast1060_dcscm_dice：DCSCM 演示板支援硬體 DICE（需要 MCUBoot 作為引導程式）
  • ast1060_prot：採用 Intel 影像格式的 PROT 模組

# Aspeed PFR User Guide

這份文件是針對 PFR 對策所撰寫，所以主要會搭配 AspeedTech-BMC/aspeed-zephyr-project 進行說明，只有這份文件中才會提到 ast1060_dcscm 相關的內容，不過實際上內容十分簡陋。

# AST1060_Zephyr_SDK_User_Guide

這份文件是針對 AST1060 IC 所撰寫，所以主要會搭配 AspeedTech-BMC/zephyr 中的 AST1060_EVB 與其範例程式，這份文件中只有提到 AST1060_EVB 相關的內容，內容同樣也是十分簡陋。

# Aspeed_Zephy_SDK_User

這份文件是針對 AspeedTech-BMC/zephyr 所撰寫，雖然內容相對完整，不過這份文件中只有提到 AST1030 與 AST2600，後續並沒有整合其他產品線，但前兩份文件還是會把問題甩給這份文件。
