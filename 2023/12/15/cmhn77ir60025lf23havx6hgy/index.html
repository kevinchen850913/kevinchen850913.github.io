BMC(6)-Metadata 學習筆記

發表於2023-12-16|更新於2025-11-06

# Metadata 簡介

Metadata 元資料在臺灣又譯作「詮釋資料」，元資料的意思是「關於資料的資料」。元資料被定義為提供有關資料的一個或多個方面的資訊的資料，它用於總結有關數據的基本信息，可以使追蹤和處理特定數據變得更加容易。

我覺得 Metadata 不適合當作一種分類，而是一種資料的屬性，當某個資料內容為描述其他資料時，這個資料就是 Metadata。

# Metadata 元資料分類

# Metadata 主要

  • Recipes 食譜 (.bb) 通常描述單一套件的建置指令
  • PackageGroups 包組（special .bb）將套件分組在一起形成目錄樹
  • Classes 類別 (.bbclass) 通用功能的繼承機制
  • Configuration 配置（.conf）驅動建構過程的整體行為

# Other Metadata 更多

  • Append files 追加檔案 (.bbappend)，為類似名稱的 .bb 檔案定義附加元數據，可以新增或覆蓋先前設定的值。
  • Include files 包含檔案 (.inc)，與 include 指令一起使用的文件，也可以包含在 require 中，檔案通常是透過 BBPATH 變數找到。

# Other 其他

OpenBMC 過濾上述副檔名後，還有不少檔案。

  • 文字類型檔案 .md .txt .rst .in (給人看的？)
  • 程式碼 .c .py
  • 腳本類 .sh
  • 二進制檔 MIT
  • 補丁？.patch

# Recipe 食譜

  • 最常見的元資料形式：食譜 (Recipe)

  • 食譜提供 “食材清單” 和 “烹飪說明”

  • 定義 bitbake 用於建立二進位包的設定和一組任務

  • Recipes
    BitBake Recipes 由檔案副檔名表示.bb，是最基本的元資料檔案。這些配方檔案為 BitBake 提供以下內容：

    • 有關包的描述性資訊（作者、主頁、許可證等）
    • 食譜的版本
    • 現有依賴項（建置和運行時相依性）
    • 原始碼所在的位置以及如何取得它
    • 原始碼是否需要任何補丁、在哪裡可以找到它們以及如何應用它們
    • 如何配置和編譯原始碼
    • 如何將產生的工件組裝到一個或多個可安裝套件中
    • 在目標電腦上安裝一個或多個已建立的套件的位置
      在 BitBake 或使用 BitBake 作為其建置系統的任何專案的上下文中，具有副檔名的檔案.bb 稱為配方。

# Classes 類別

別檔案由 .bbclass 副檔名表示，包含可在元資料檔案之間共用的有用資訊。BitBake 原始碼樹目前附帶一個名為 base.bbclass. 您可以在目錄中找到該檔案 classes。類別 base.bbclass 文件很特殊，因為它始終自動包含在所有配方和類別中。此類別包含標準基本任務的定義，例如取得、解包、配置（預設為空）、編譯（執行任何存在的 Makefile）、安裝（預設為空）和打包（預設為空）。這些任務通常會被專案開發過程中新增的其他類別覆蓋或擴展。

# Configuration 配置

設定檔由 .conf 副檔名表示，定義了管理專案建置過程的各種設定變數。這些檔案分為幾個區域，定義機器配置、分發配置、可能的編譯器調整、通用配置和使用者配置。主要設定檔是範例 bitbake.conf 文件，它位於 BitBake 原始碼樹 conf 目錄中。

# Append Files 追加

追加文件，是具有.bbappend 檔案副檔名、擴充或覆蓋現有配方檔案中的資訊的文件。命名附加檔案時，可以使用「%」通配符來允許匹配配方名稱。「%」字元的使用受到限制，因為它只能直接用在附加檔案名稱的 .bbappend 部分前面。
