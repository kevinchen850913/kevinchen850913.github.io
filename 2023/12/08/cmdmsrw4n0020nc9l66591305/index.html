# Bitbake 語法

BitBake 檔案有自己的語法。該語法與其他幾種語言有相似之處，但也有一些獨特的功能。本節介紹可用的語法和運算子並提供範例。
OpenBMC(4)-Bitbake_Operators

OpenBMC(5)-Bitbake_Execution

# 共享功能

BitBake 允許透過包含檔案 (.inc) 和類別檔案 ( .bbclass) 進行元資料共用。例如，假設您有一項常見功能，例如您想要在多個配方之間共用的任務定義。在這種情況下，建立一個 .bbclass 包含通用功能的文件，然後使用 inherit 配方中的指令繼承該類別將是共享任務。

本節介紹 BitBake 提供的機制，讓您在配方之間共用功能。這些機制包括 include、inherit、INHERIT、require。

BitBake 使用 BBPATH 變數來定位所需的包含檔案和類別檔案。BitBake 會在位於 BBPATH 中的 classes 子目錄中搜尋 include 和 require 。

# INHERIT

建立設定檔 (.conf) 時，可以使用 INHERIT 設定指令來繼承類別。BitBake 僅在設定檔中使用時支援此指令。

# inherit

編寫配方或類別檔案時，可以使用指令 inherit 繼承類別的功能 (.bbclass)。.bbBitBake 僅在配方和類別檔案（即和）中使用時支援此指令.bbclass。

# include

該命令使 BitBake 解析您指定的任何文件，並將該文件插入到該位置。該指令與 Make 中的等效指令非常相似，不同之處在於，如果包含行上指定的路徑是相對路徑，則 BitBake 會定位它可以在 BBPATH 中找到的第一個檔案。

# require

該指令的行為與 include 類似，但如果找不到要包含的文件，BitBake 會引發解析錯誤。

# 其他語法

# 大括號語法

如果配方在函數內右大括號沒有前導空格，則 BitBake 會產生錯誤。

# 多行語法

BitBake 在解析語句之前將任何以反斜線字元 \ 結尾的行與以下行連接起來。 \ 字元最常見的用途是將變數分配拆分為多行， \ 字元及其後面的換行符都會被刪除，因此值中不會出現換行符號。

# Bitbake 方法

與大多數語言一樣，函數是用於將操作建構成任務的建構塊。無論函數類型為何，您都只能在類別 (.bbclass) 和配方 (.bb 或.inc) 檔案中定義它們。

  • Shell 函數：以 shell 腳本編寫並直接作為函數、任務或兩者執行的函數。它們也可以被其他 shell 函數呼叫。
  • BitBake 風格的 Python 函數：用 Python 編寫並由 BitBake 或其他使用 bb.build.exec_func ().
  • Python 函數：用 Python 編寫並由 Python 執行的函數。
  • 匿名 Python 函數：在解析過程中自動執行的 Python 函數。

# 外殼函數

用 shell 腳本編寫的函數可以直接當作函數、任務或兩者一起執行。它們也可以被其他 shell 函數呼叫。

更多範例程式

套用所有覆蓋後，您可以使用 bitbake -e recipename 命令查看最終組裝的函數。
