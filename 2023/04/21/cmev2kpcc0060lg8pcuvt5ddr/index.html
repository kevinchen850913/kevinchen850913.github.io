# String 介紹

在 C++ 中 string 是一個存放 char 的序列容器，可用於存儲和操作字串，避免了使用 char 型陣列時容易出現的空間分配、越界、不易修改等問題，所以文字處理盡量不要使用 char[] 。

String 的特色，可與 C 語言風格字串雙向轉換。
